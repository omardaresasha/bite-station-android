# Bite Station — Android App

هذا المشروع يحول موقع Bite Station الحالي إلى تطبيق Android.

## فتح المشروع
1. ثبّت Android Studio.
2. افتح مجلد `android` كمشروع.
3. انتظر Gradle Sync.
4. شغّل التطبيق على جهاز Android أو Emulator.

## إخراج APK
من Android Studio:
Build > Build Bundle(s) / APK(s) > Build APK(s)

## إخراج Google Play
Build > Generate Signed Bundle / APK > Android App Bundle.

Package name:
com.bitestation.app

Version:
1.0.0 (versionCode 1)

الموقع الأصلي مضمّن داخل:
android/app/src/main/assets/www/
